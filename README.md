# Steno Practice Android App (starter)
Hindi-focused starter app with dictation TTS, speed selector, timed typing test, approximate word matching, word list and practice tips.

## Build APK
1. Install Android Studio (latest stable) and Android SDK Platform 35.
2. Open this folder in Android Studio.
3. Wait for Gradle sync. If prompted, use compatible JDK (Android Studio bundled JDK).
4. Connect Android phone with USB debugging, or create an emulator.
5. Click Run ▶ to install.
6. APK: Build > Build Bundle(s) / APK(s) > Build APK(s). Android Studio shows the APK path.

Note: Hindi TTS availability depends on Hindi voice installed on the device (Settings > Text-to-speech).
This is a starter prototype, not a polished Play Store release. Dictionary contains words only—not Pitman shorthand outlines. Improve UI, audio passages, progress persistence, and real stenography outline/recognition before publishing.
